# Установка на сервер

Сервер — VPS или мини-ПК в клубе с Ubuntu 22.04 / 24.04. Для пилота (1 стол × 1 ПК) хватает 2 vCPU, 4 ГБ RAM, 40 ГБ диска, публичного IPv4 и канала от 100 Мбит/с; виртуализация KVM (на OpenVZ Docker не работает).

## Установка одной командой

Под root (или через `sudo -i`) в консоли сервера — SSH или веб-консоль провайдера:

```bash
curl -fsSL https://raw.githubusercontent.com/alisher-15/pokercam/main/deploy/install.sh | bash -s -- --ref main
```

Пока этапы не влиты в `main`, вместо `main` укажите ветку последнего этапа (например, `stage-5/android`) — и в адресе скрипта, и в `--ref`.

Скрипт:

1. ставит Docker (если его нет);
2. кладёт код в `/opt/pokercam`;
3. создаёт `/opt/pokercam/.env` с новыми секретами, паролем базы и администратора, адресом этого сервера (`--ip`, по умолчанию определяется сам) и часовым поясом (`--timezone`, по умолчанию `Asia/Almaty`);
4. открывает порты в ufw (если он включён): TCP 8000 (backend и админка), TCP 3000 (media-server), TCP и UDP 40000–40003 (видео WebRTC);
5. запускает postgres, backend и media-server и создаёт администратора.

В конце печатает адрес админки, логин и пароль (пароль показывается один раз; он же в `/opt/pokercam/.env`).

Если у провайдера свой файрвол (группа безопасности), откройте в нём те же порты.

## Привязка телефона-камеры

Пока нет Windows-клиента (этап 6), код привязки выдаёт сервер:

1. Клиент с оплаченным месяцем и столом 1 — на сервере:

   ```bash
   cd /opt/pokercam && docker compose exec backend python -m app.cli create-client "Название клиента"
   ```

   Команда печатает ключ активации клиента для ПК — сохраните его. Или в админке `http://IP:8000/admin`: сначала «Бренды» → создать бренд, затем «Клиенты» → создать клиента (с ним создаётся стол 1).
2. Код привязки — на сервере:

   ```bash
   cd /opt/pokercam && docker compose exec backend python -m app.cli pairing-code "Название клиента"
   ```

   Код из 6 цифр живёт 5 минут.
3. В приложении камеры: «Ввести код вручную» → адрес сервера `http://IP:8000` и код.

Приложение камеры: https://github.com/alisher-15/pokercam/releases/download/camera-apk/pokercam-camera.apk

## Обновление

Тот же скрипт ещё раз (с нужной `--ref`): обновит код и перезапустит сервисы; `.env` с секретами сохраняется.
