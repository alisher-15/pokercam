# Установка на сервер

Сервер — VPS или мини-ПК в клубе с Ubuntu 22.04 / 24.04. Для пилота (1 стол × 1 ПК) хватает 2 vCPU, 4 ГБ RAM, 40 ГБ диска, публичного IPv4 и канала от 100 Мбит/с; виртуализация KVM (на OpenVZ Docker не работает).

## Установка одной командой

Под root (или через `sudo -i`) в консоли сервера — SSH или веб-консоль провайдера:

```bash
curl -fsSL https://raw.githubusercontent.com/alisher-15/pokercam/main/deploy/install.sh | bash -s -- --ref main
```

Пока этапы не влиты в `main`, вместо `main` укажите ветку последнего этапа (например, `stage-5/android`) — и в адресе скрипта, и в `--ref`.

Скрипт:

1. ставит Docker (если его нет);
2. кладёт код в `/opt/pokercam`;
3. создаёт `/opt/pokercam/.env` с новыми секретами, паролем базы и администратора, адресом этого сервера (`--ip`, по умолчанию определяется сам) и часовым поясом (`--timezone`, по умолчанию `Asia/Almaty`);
4. открывает порты в ufw (если он включён): TCP 8000 (backend и админка), TCP 3000 (media-server), TCP и UDP 40000–40003 (видео WebRTC);
5. запускает postgres, backend и media-server и создаёт администратора.

В конце печатает адрес админки, логин и пароль (пароль показывается один раз; он же в `/opt/pokercam/.env`).

Если у провайдера свой файрвол (группа безопасности), откройте в нём те же порты.

## Программа для ПК клуба (Windows 10/11)

https://github.com/alisher-15/pokercam/releases/download/viewer-windows/pokercam-viewer-windows.zip — распакуйте в любую папку и запустите `viewer_windows.exe` (до установщика этапа 8 Windows предупредит о неподписанной программе: «Подробнее» → «Выполнить в любом случае»). При первом запуске — адрес сервера `http://IP:8000` и ключ активации клиента. Дальше — список столов, «Привязать телефон» (QR и код), «Открыть» или «В новом окне».

## Привязка телефона-камеры и просмотр

Компьютер клуба — программа выше; без неё — страница в браузере на media-server.

1. Клиент с оплаченным месяцем и столом 1 — на сервере:

   ```bash
   cd /opt/pokercam && docker compose exec backend python -m app.cli create-client "Название клиента"
   ```

   Команда печатает ключ активации клиента — сохраните его. Или в админке `http://IP:8000/admin`: сначала «Бренды» → создать бренд, затем «Клиенты» → создать клиента (с ним создаётся стол 1). Потерянный ключ — «Перевыпустить ключ» на странице клиента.
2. На компьютере клуба откройте `http://IP:3000/viewer/`: адрес сервера `http://IP:8000` и ключ активации. Страница запоминает подключение (в админке она появится в «Компьютерах»).
3. «Привязать телефон» показывает QR-код и код из 6 цифр (живёт 5 минут). В приложении камеры наведите камеру на QR или «Ввести код вручную» → адрес `http://IP:8000` и код.

   Без страницы код выдаёт сервер: `cd /opt/pokercam && docker compose exec backend python -m app.cli pairing-code "Название клиента"`.
4. На странице — видео стола, телеметрия телефона, предупреждения и настройки камеры (рядом с каждой — за сколько камера её применила).

К столу подключается столько зрителей, сколько задано в `MAX_VIEWERS_PER_TABLE` (в пилоте 1): пока страница открыта на одном компьютере, второй не подключится.

Приложение камеры: https://github.com/alisher-15/pokercam/releases/download/camera-apk/pokercam-camera.apk

## Обновление

Тот же скрипт ещё раз (с нужной `--ref`): обновит код и перезапустит сервисы; `.env` с секретами сохраняется.
